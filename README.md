# 星河排班 (Xinghe Shift Schedule)

一款纯本地的鸿蒙（HarmonyOS）排班应用：用月历排班、按自定义规则校验、自动统计工时与休息。**不申请网络权限，所有数据仅保存在本机。**

## 功能

### 首页 · 排班
- **月历排班**：点日期查看/编辑当日班次（开始-结束时间，支持跨天），可标记休息日
- **开始排班开关**：点「开始排班」进入编辑态，编辑完成点「完成排班」，平时界面保持清爽
- **今日日程**：班次列表 + 备忘录 + 当日待办（勾选完成）
- **目标进度**：本月已排 / 目标工时进度条，还需排多少一目了然
- **规则提醒**：排班违反规则时红字提示具体哪天、差多少
- **批量操作**（勾选班次后，未勾选默认本日全部）：
  - **加闹钟**：按系统提醒在班次开始前响铃（不提前 / 提前30分钟 / 1小时 / 2小时）
  - **加日历**：写入系统日历（跨天班次自动顺延）
- **排班工具**：
  - **同步到某月**：把当前月全部班次一键复制到目标月份（覆盖前确认）
  - **复制本日班次**：把所选日的班次复制到另一天
  - **自动排满本月**：按规则把本月未排的日期自动生成班次，排够目标工时为止
  - **区间排班**：选一段日期按目标工时均摊排班

### 统计
- 工时进度环（已排 / 目标 / 还需排）
- 休息天数与休息时长（对照目标）
- 连续上班天数（当前连续 / 本月最长）
- 每日工时柱状分布图
- 规则提醒汇总
- 点标题用官方年月选择器跳转任意月份

### 我的
- **外观**：跟随系统 / 浅色 / 深色（深色模式下启动画面与首帧同步适配）
- **排班规则**：所有规则可自定义（见下）
- **数据**：导出（复制到剪贴板）/ 导入（粘贴导出数据）/ 清空
- **关于**：包名、实时版本号（versionName (versionCode)）、检查更新

## 排班规则

| 规则 | 默认值 |
|---|---|
| 每月目标工时 | 144 小时 |
| 每日最少工时 | 6 小时 |
| 除休息日外每日最少工时 | 不限 |
| 班次间最少间隔 | 60 分钟 |
| 每月最少休息天数 | 4 天 |
| 每月最少休息时长 | 40 小时 |
| 最长连续上班天数 | 6 天 |
| 单段最长连续工作 | 360 分钟（6 小时） |
| 超时后强制休息 | 60 分钟 |

规则校验为**提醒式**：违反时红字提示，不强制拦截。自动排班会遵守目标工时、每日最少工时、单段时长上限与连续天数上限。

## 语言与深色模式

- 中文 / 英文跟随系统语言
- 深色模式跟随系统，或在应用内强制深浅色；启动画面用 `dark` 限定词资源自适应

## 数据与隐私

- **不申请网络权限**，无登录、无云同步、无数据上传
- 数据保存在应用本地 preferences，卸载即清除
- 导出为 JSON 文本（复制到剪贴板），可在设备间粘贴导入

## 构建

使用 DevEco Studio（API 12+，targetSdk 26）打开项目根目录，直接运行 `entry` 模块即可。

```bash
hvigorw assembleHap --mode module -p product=default -p buildMode=debug
```

- 签名配置不入库：仓库保留 `build-profile.example.json5` 模板，`build-profile.json5` 本体与签名材料（`*.p12` / `*.cer` / `*.p7b`）已被 `.gitignore` 忽略
- Release 构建已开启代码混淆（`entry/obfuscation-rules.txt`）

## 目录结构

```
entry/src/main/ets/
├── entryability/        # 应用入口（安全区避让、外观初始化）
├── model/               # 数据模型与排班规则类型
├── service/             # ScheduleService：本地存储、规则校验、统计、同步/自动排班
├── pages/               # Index（HdsTabs 悬浮底栏）+ 排班/统计/我的 三页
├── utils/               # 系统日历与提醒代理
└── view/                # （预留）
```
