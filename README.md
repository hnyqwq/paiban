# 星河排班 (Xinghe Shift Schedule)

一款纯本地的鸿蒙（HarmonyOS）排班应用：用月历排班、按自定义规则校验、自动统计工时与休息。**不申请网络权限，所有数据仅保存在本机。**

## 功能

底栏四个页面：**日程 / 排班 / 统计 / 我的**。

### 日程（第一页）
- **月历**：支持周日起始 / 周一开始（在「我的」中设置）；选中日期实心蓝底白字，今天显示「今日」标记（排了班显示今日 · 6h，休息日显示今日 · 休）；两点日历实时联动（本页选中/翻月，排班页同步）
- **当日日程**：只读展示当天班次时间与时长，休息日显示「休」
- **备忘录**：随选中的日期保存
- **待办**：当日至办清单，勾选完成、删除

### 排班（第二页）
- **月历**：与日程页联动
- **排班编辑**：点「开始排班」进入编辑态——
  - **添加班次**：逐段编辑（开始-结束），支持一天多段；时间输入失焦自动规范化（`13`→`13:00`、`20.30`→`20:30`）
  - **预设模板**：早班 06-14 / 白班 09-17 / 晚班 14-22 / 夜班 22-06 一键填入；**自定义预设规则**来自「我的」中保存的班次模板，可再调整后一次加齐
  - **编辑/删除班次**：点「编辑」修改已有班次时间
  - **标记休息**：标记/取消休息日（当天已有班次时会先确认，避免误删）
  - **加日历**：勾选班次（未勾选默认本日全部）写入系统日历，已存在的事件不重复添加；手动删除日历事件后可重新添加
  - 点「完成排班」退出编辑态
- **本月概览**：目标工时进度条 + 规则提醒，实时刷新
- **排班工具**（均先弹说明、讲清步骤再开始）：
  - **自动排本月 / 排一段日期**：按规则与目标工时自动生成班次；两遍式均摊——先确定真实可排天数（排除强制休息日），剩余工时按真实天数分摊，保证月总时长凑够；所有时段限当天内完成，不产生凌晨时间
  - **复制一月 / 复制一天 / 复制一段时间**：把已有班次复制到目标月份/日期/区间（覆盖前确认）
- **提醒工具**：批量加日历（选日期区间，区间内全部班次一次写入）

### 统计（第三页）
- 工时进度（已排 / 目标 / 还需排）
- 休息天数与休息时长（对照目标）
- 连续上班天数（当前连续 / 本月最长）
- 每日工时柱状分布图
- 规则提醒汇总
- 点标题用官方年月选择器跳转任意月份

### 我的（第四页）
- **排班规则**：所有规则可自定义（见下）；固定班次模板逐段编辑（自动识别与拼接）
- **数据**：导出（复制到剪贴板）/ 导入（粘贴导出数据，使用系统安全控件 PasteButton）/ 清空
- **外观**：跟随系统 / 浅色 / 深色（深色模式下启动画面与首帧同步适配）；日历显示顺序（周日起始 / 周一开始）
- **关于**：包名、实时版本号（versionName (versionCode)）、检查更新
- **隐私协议**：点击在系统浏览器打开

## 排班规则

| 规则 | 默认值 |
|---|---|
| 每月目标工时 | 144 小时 |
| 每日最少工时 | 6 小时 |
| 除休息日外每日最少工时 | 不限 |
| 班次间最少间隔 | 60 分钟 |
| 每月最少休息天数 | 4 天 |
| 每月最少休息时长 | 40 小时 |
| 最长连续上班天数 | 6 天 |
| 单段最长连续工作 | 360 分钟（6 小时） |
| 超时后强制休息 | 60 分钟 |

规则校验为**提醒式**：违反时红字提示，不强制拦截。自动排班遵守目标工时、每日最少工时（作为下限，天数不够时单日自动往上加）、单段时长上限与连续天数上限；配置了固定班次模板时，模板总时长达到当日应排时长才按模板排，否则按时长自动拆段。

## 语言与深色模式

- 中文 / 英文跟随系统语言
- 深色模式跟随系统，或在应用内强制深浅色；启动画面用 `dark` 限定词资源自适应

## 数据与隐私

- **不申请网络权限**，无登录、无云同步、无数据上传
- 数据保存在应用本地 preferences，卸载即清除
- 导出为 JSON 文本（复制到剪贴板），可在设备间粘贴导入
- **系统日历**：仅在用户主动点「加日历」时写入班次事件；写入前查询目标时间段内已有事件用于去重，不读取、修改、删除日历中的其他内容
- **提醒代理**：班次响铃提醒功能暂未开放（审核通过后上线），未申请后台行为
- 隐私协议见「我的」页底部链接

## 构建

使用 DevEco Studio（API 12+，targetSdk 26）打开项目根目录，直接运行 `entry` 模块即可。

```bash
hvigorw assembleHap --mode module -p product=default -p buildMode=debug
```

- 签名配置不入库：仓库保留 `build-profile.example.json5` 模板，`build-profile.json5` 本体与签名材料（`*.p12` / `*.cer` / `*.p7b`）已被 `.gitignore` 忽略
- Release 构建已开启代码混淆（`entry/obfuscation-rules.txt`）

## 目录结构

```
entry/src/main/ets/
├── entryability/        # 应用入口（安全区避让、外观初始化）
├── model/               # 数据模型与排班规则类型（含时间规范化工具）
├── service/             # ScheduleService：本地存储、规则校验、统计、复制/自动排班
├── pages/               # Index（HdsTabs 悬浮底栏）+ 日程/排班/统计/我的 四页
├── utils/               # 系统日历写入
└── view/                # CalendarView：日程页与排班页共用的月历组件
```
